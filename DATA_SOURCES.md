# Data sources and attribution

Garda Oracle is designed around sources that permit automated access and
reuse. Raw observation and forecast downloads are intentionally excluded from
the Git repository; the fetch scripts recreate them under `data/`.

This document records the project interpretation of the source metadata as of
25 July 2026. It is not legal advice. Reusers should verify the linked source
terms for their own use.

## Meteotrentino / Provincia Autonoma di Trento

The live panel reads the public `ultimiDatiStazione` endpoint for station
T0193. The Dati Trentino catalogue describes the recent automatic-station
dataset as Creative Commons Attribution. Garda Oracle conservatively treats
and attributes it as
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- [Recent automatic weather-station data](https://dati.trentino.it/en/dataset/dati-recenti-delle-stazioni-meteo)
- [Station catalogue resource](https://dati.trentino.it/dataset/meteo-data/resource/6c1b0cbd-f28d-4f1c-be4e-a68a48b0e55f)

The historical wind and direction downloads used for model labels come from
the Meteotrentino historical-station resource. Its resource metadata states
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), even though
some higher-level catalogue views display a broader dataset licence. This
project relies on the resource-specific CC0 declaration:

- [Historical station-data resource and licence metadata](https://dati.trentino.it/dataset/dati-storici-stazioni-meteorologiche/resource/56bbbffe-2876-4acb-a47a-470325628d7a)

Attribution used by the project:

> Weather observations: Meteotrentino / Provincia Autonoma di Trento.
> Processed by Garda Oracle.

The automatic observations are telemetry and may not have undergone final
validation. Garda Oracle converts wind speed from metres per second to knots,
joins speed and direction by timestamp, aggregates fixed local-time windows
and derives binary regime labels.

## Open-Meteo

Open-Meteo states that API data are available under
[CC BY 4.0](https://open-meteo.com/en/license), including redistribution and
commercial reuse with attribution. API access conditions and rate limits are
separate from the data licence.

Attribution used by the project:

> Weather forecast and reanalysis data: Open-Meteo (CC BY 4.0).
> Processed by Garda Oracle.

The project uses four grid points around the Alps and Po Valley. It aggregates
hourly pressure, temperature, cloud, radiation, precipitation, humidity and
100-metre wind fields into the features documented in
[`docs/model-card.md`](docs/model-card.md).

The Historical Weather API supplies ERA5 reanalysis through Open-Meteo. ERA5
is produced by the Copernicus Climate Change Service and ECMWF; the underlying
dataset is also published under CC BY:

- [ERA5 hourly data on single levels](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels)
- [ERA5 dataset DOI](https://doi.org/10.24381/cds.adbb2d47)

## Repository artefacts

The repository distributes:

- source code, documentation and frozen numerical model parameters under the
  GNU Affero General Public License v3.0 only in [`LICENSE`](LICENSE);
- no raw Meteotrentino or Open-Meteo downloads.

The coefficient file is generated by this project from the sources above.
When redistributing or substantially modifying the trained model, retain this
data-provenance notice and the Open-Meteo attribution. The AGPL-3.0-only
licence covers the project-authored code and artefacts; it does not replace
any third-party data terms.
