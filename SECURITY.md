# Security policy

## Reporting

Please report security issues through a
[private GitHub security advisory](https://github.com/s1st/garda-oracle/security/advisories/new).
Do not place credentials, exploit details or private data in a public issue.

For an accidentally committed credential, revoke or rotate it immediately;
removing it from the latest commit is not sufficient.

## Supported version

Only the current `main` branch is supported.

## Safety scope

Garda Oracle is not an official weather-warning or safety service. A wrong
wind forecast is a model-quality issue rather than a software-security
vulnerability. Urgent weather and water-safety decisions should use official
warnings and current local conditions.
